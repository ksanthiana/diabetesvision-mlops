
# DiabetesVision MLOps

An image-based diabetic retinopathy classification and MLOps project.

## Project Overview

This project extends previous work on Diabetes Health Indicators ML into an image-based machine learning pipeline.

The system aims to:
- Classify diabetic retinopathy severity from retinal images.
- Provide image-based predictions through an API.
- Support bulk image uploads.
- Enable model retraining.
- Monitor model performance and availability.
- Evaluate scalability through load testing.

## Technologies

- Python
- TensorFlow / Keras
- MobileNetV2
- FastAPI
- Streamlit
- Docker
- Locust
